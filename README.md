# О проекте

`Cryptum` — консольное приложение для шифрования и расшифрования текста и файлов, реализованное на C++17. В рамках проекта реализованы 6 алгоритмов, объединённых в отдельные динамически загружаемые библиотеки. Основная программа выбирает нужный алгоритм во время запуска и вызывает общий интерфейс плагина.

Проект поддерживает сборку динамических библиотек в форматах `.so` для Linux, `.dylib` для macOS и `.dll` для Windows.

# Реализованные алгоритмы

## 1. RC4

**RC4** — симметричный потоковый шифр, который формирует псевдослучайную последовательность байтов и накладывает её на исходные данные с помощью операции XOR. Внутреннее состояние алгоритма представляет собой перестановку из 256 байтов. Сначала выполняется алгоритм подготовки ключа KSA, который перемешивает состояние на основе ключа, после чего алгоритм PRGA последовательно создаёт байты ключевого потока.

В текущей реализации используется ключ размером 16 байт. Шифрование и расшифрование выполняются одной и той же операцией: повторное применение RC4 с тем же ключом возвращает исходные данные. Размер выходного файла совпадает с размером входного.

## 2. ChaCha20

**ChaCha20** — симметричный потоковый шифр, основанный на операциях сложения, побитового XOR и циклического сдвига. Алгоритм обрабатывает внутреннее состояние из 16 чисел размером 32 бита и выполняет 20 раундов преобразований. Основной частью алгоритма является функция `quarter_round`, которая перемешивает четыре элемента состояния.

В проекте используется 32-байтный секретный ключ и 12-байтный nonce, которые объединены в один ключевой файл размером 44 байта. Алгоритм создаёт блоки ключевого потока размером 64 байта и накладывает их на данные с помощью XOR. Поэтому операции шифрования и расшифрования выполняются одинаково, а размер результата равен размеру исходных данных.

## 3. Atbash

**Atbash** — простой симметричный шифр замены, который заменяет каждый символ на противоположный символ в алфавите. Например, для английского алфавита буква `A` заменяется на `Z`, `B` — на `Y`, а `a` — на `z`. В реализации также предусмотрено преобразование русских букв, представленных в кодировке Windows-1251.

Алгоритм не использует ключ. Символы, которые не относятся к поддерживаемым буквам, остаются без изменений. Atbash является обратным сам себе, поэтому для шифрования и расшифрования применяется одна и та же функция.

## 4. Vernam

**Vernam** — симметричный шифр, основанный на побитовой операции XOR между исходными данными и ключом. Каждый байт текста складывается по XOR с соответствующим байтом ключа. Если данные длиннее ключа, ключ начинает использоваться заново с первого байта.

В текущей реализации используется ключ размером 32 байта. Операции шифрования и расшифрования полностью одинаковы: повторное применение того же ключа к шифротексту восстанавливает исходные данные. Размер выходного файла не меняется.

## 5. Vigenere-256

**Vigenere-256** — байтовая версия шифра Виженера, рассчитанная не только на буквы, но и на произвольные бинарные данные. При шифровании к каждому байту исходного файла прибавляется соответствующий байт ключа. При расшифровании байт ключа вычитается из зашифрованного байта. Все операции выполняются в диапазоне от 0 до 255.

В реализации используется ключ размером 16 байт. Если входные данные длиннее ключа, ключ повторяется циклически. Размер зашифрованных и расшифрованных данных совпадает с размером исходного файла.

## 6. ElGamal

**ElGamal** — асимметричный криптографический алгоритм, основанный на вычислениях в конечном поле и сложности задачи дискретного логарифмирования. Для шифрования используется открытая часть ключа, вычисляемая на основе закрытого ключа, а для расшифрования применяется закрытый ключ.

В проекте используются параметры `P = 65537` и `G = 3`, а закрытый ключ хранится в виде 4 байтов. Каждый исходный байт преобразуется в пару чисел `C1` и `C2`. Каждое из них занимает 4 байта, поэтому один байт исходных данных превращается в 8 байт шифротекста. При расшифровании вычисляется общий секрет и обратное число по модулю, после чего восстанавливается исходный байт.
